## Phase 1 — immutable and exact release inputs

- [ ] **P1 / AGG6-01:** make the generated release-provenance asset namespace exact. The generating
  task must fail closed on unexpected sibling files before/after generation, and the artifact checker
  must reject unexpected members under that namespace. Add a regression that seeds an ignored stale
  sibling and proves an ordinary non-clean release cannot package it.
- [ ] **P2 / AGG6-02:** bind release compilation and packaging to an immutable Git source identity.
  Prefer a disposable commit-addressed snapshot/worktree or a complete content-addressed input set
  consumed by every source/resource/package task. Add a deterministic barrier test that mutates a
  real tracked input after provenance verification and proves no signed/upload-ready artifact can
  claim the original tree while consuming the changed bytes.

Acceptance: release artifacts contain exactly the intended generated provenance asset and all
compiled/resource bytes come from the immutable source identity recorded in that asset. Direct
release entry points fail closed; debug builds remain usable from a dirty development tree.

## Phase 2 — finish recorder native/storage phase separation

- [ ] **P3 / AGG6-03:** split `VideoRecorder.stop()` into checked native/container finalization and
  a frozen post-native storage/publication continuation on a separate owned executor. At successful
  native classification, free the same-Engine REC lane, teardown flag, and microphone handoff while
  preserving capture-specific publication/status identity. A stalled extractor/provider call must
  not block a second recording and must remain recoverable through the durable pending-row protocol.
- [ ] **P4 / AGG6-07:** replace label-only native-owner cleanup coverage with injected throwing
  operations or a structural production-owner enumeration that reaches every actual release owner
  and proves owner retention, quarantine, and no later native phase on failure.
- [ ] **P5 / AGG6-08:** replace the inert blocked-storage latch test with an executor-level
  integration test that genuinely blocks the post-native tail, exercises Engine finalization/release,
  admits and completes a second recording, and verifies independent terminal outcomes.
- [ ] **P6 / AGG6-09:** update the architecture to describe native classification separately from
  the storage tail. Remove `RecorderFinalizationOwner.taskCompleted` if the new execution boundary
  leaves it without an observable owner, and add a docs contract for the split.

Acceptance: after all native recorder owners are proven released, a blocked first-clip storage tail
cannot delay same-Engine REC admission, overlap native owners, corrupt callbacks, or trigger false
quarantine; true native hangs still fail closed.
